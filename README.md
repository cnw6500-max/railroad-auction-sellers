# Railroad Collectibles Auction – Seller Overview

A one-page website version of the seller deck.

## Publish on GitHub Pages

1. Sign in to GitHub as **cnw6500-max** and create a new public repository (for example `railroad-auction-sellers`).
2. Upload `index.html` and the `images` folder (drag both onto the repository's "Add file → Upload files" page) and commit.
3. Open **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
4. After a minute the page is live at:
   `https://cnw6500-max.github.io/railroad-auction-sellers/`

Fill in the launch date, contact and web address in the "Joining" section of `index.html` before sharing.
